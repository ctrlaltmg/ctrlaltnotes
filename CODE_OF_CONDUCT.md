# Code of conduct

CtrlAltNotes is a small project that wants to be welcoming to everyone who uses or improves it.

## Expected

* Be respectful and patient, in issues, pull requests and discussions.
* Assume good intent; criticise ideas and code, not people.
* Keep discussions on topic and in public, except security reports (see `SECURITY.md`).

## Not accepted

* Harassment, insults, discriminatory language or imagery, or personal attacks.
* Publishing anyone's private information without permission.
* Sustained disruption of discussions.

## Enforcement

The maintainer may edit or remove comments, close threads, and block accounts that break these
rules. Report problems privately by opening a GitHub security advisory marked "conduct", or by
contacting the maintainer through their GitHub profile. Reports are kept confidential.
